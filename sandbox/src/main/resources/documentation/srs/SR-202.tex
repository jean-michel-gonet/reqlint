\softwarerequirement{SR-202}{Maximum Capacity Cap}
\label{SRS-202}
\paragraph{Links} \nameref{ER-200}

The server shall ensure the updated token count $T_{updated}$ never exceeds $B_{max}$:

\begin{equation}
    T_{updated} = \min(B_{max}, T + \Delta T)
    \label{eq:maximum-capacity-cap}
\end{equation}
